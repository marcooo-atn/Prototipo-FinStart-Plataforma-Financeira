# Prototipo-FinStart-Plataforma-Financeira
Um prototipo de um site para resolver problemas financeiros com o foco para pessoas mais jovens que não entendem tanto do assunto, e junto com o auxílio de um assistente Copiloto para tirar dúvidas e fazer propostas financeiras, além de poder falar como a conta vem se desenvolvendo, seus lucros e gastos sempre a mostra.
